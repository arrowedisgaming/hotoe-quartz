# Role Log

One row per player-character skill or characteristic roll, per session. NPC and monster rolls are excluded.

Columns:

- **Character** — PC name
- **Skill** — the skill or characteristic name only
- **Roll** — d100 number rolled, with target after a slash where known (e.g. `42 / 65`)
- **Result** — `Fumble` / `Failure` / `Success` / `Hard Success` / `Extreme Success` / `Critical`
- **In Combat** — `Yes` if during an active combat round, otherwise `No`
- **Notes** — context, SAN/MP lost, damage, weapon, target, opposed-roll outcome, qualifiers
